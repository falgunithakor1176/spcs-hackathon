# SPCS Seed Data Pipeline

This directory contains the highly realistic, algorithmically generated synthetic data for the Smart Police Command Center (SPCS). This data is generated by the Python mock engine and saved to static CSV files to ensure reproducibility for database seeding and machine learning model training.

## Regeneration

If the generation logic is updated in `mock_service.py`, you can easily regenerate all the CSV datasets to reflect the new parameters.

From the `backend` directory, run:
```bash
python scripts/export_seed_data.py
```
This will instantly overwrite the CSV files in `backend/data/seed/` with fresh, perfectly modeled data.

## Files
* `crimes.csv` (~10,000 records): Historical FIR incident reports.
* `cybercrime.csv` (~1,200 records): Digital fraud and scam reports with financial data.
* `patrol_units.csv` (~24 records): Current status of police cruisers.
* `hotspots.csv` (~15 records): Modeled high-risk geographic clusters.
* `alerts.csv` (~50 records): Live incoming critical notifications.
* `predictions.csv` (~7 records): AI-driven future risk estimates.
* `patrol_routes.csv` (~3 records): Recommended patrol waypoints.

## Next Steps
These CSVs are designed to be directly imported into PostgreSQL using the `COPY` command. See `seed_db.sql` for the table schemas and import scripts, and `data_dictionary.md` for column definitions.
